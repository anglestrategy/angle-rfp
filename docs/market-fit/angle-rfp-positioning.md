# Angle/RFP Positioning

## Category
Angle/RFP is a bid qualification and commercial risk review product for creative agencies.

It is not positioned as:
- general AI proposal writing
- generic procurement software
- broad enterprise RFP collaboration

## Beachhead
- Primary buyer: new business / pitch lead
- Secondary approver: founder, MD, or commercial lead
- Target market: Saudi creative, branding, integrated, and marketing agencies

## Core job to be done
When an RFP lands, help the agency answer:

1. Should we pursue this?
2. What is commercially risky about it?
3. What does leadership need to know before we spend pitch effort?

## Phase priorities
### Phase 1
- document intake and structured extraction
- bid / no-bid recommendation
- scope-fit analysis
- budget adequacy
- pursuit-cost framing
- agency-specific contract and delivery risk
- executive brief export

### Phase 2
- Arabic / bilingual parsing
- Etimad cues
- Saudization and local-content readiness
- GCC procurement terminology support

### Phase 3
- credentials and case-study matching
- win/loss memory
- client quality notes
- bad-fit client memory
- reusable internal account notes

## Explicitly deprioritized
- response-writing automation
- broad cross-industry expansion
- generic collaboration features
- elaborate proposal design workflows
- AI-agent-first messaging

## Product outputs that should remain first-class
- `budgetAdequacy`
- `pitchCostEstimate`
- `agencyRiskFlags`
- `submissionComplexity`
- `credentialsMatch`
- `clientQualityNotes`
- `saudiComplianceReadiness`

These belong in the main brief and qualification view, not buried as secondary metadata.
